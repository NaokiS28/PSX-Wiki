# Konami Twinkle

 > [!NOTE]
 > This is a stub article and needs to be expanded upon.

 The Twinkle (GQ751) is a PlayStation based arcade board released by Konami in the mid-to-late 90s and was predominantly used to run the original versions of [Beatmania IIDX](https://www.wikipedia.org/wiki/Beatmania_IIDX){target="_blank"} from 1st style until 8th style, however it started life as being the mainboard for a photobooth machine by Konami, allowing users to print out photos as stickers with extra effects and clipart and was presumably where the Twinkle name came from.

 The system consists of a full PlayStation core, including the CPU, GPU and SPU along with a SCSI interface for a CD-ROM drive. Other optional hardware includes:
 * A video capture PCB for composite video
 * A Motorola 68000 based 'SPU' board with an IDE hard drive interface
 * An optional photo printer
 * A serial based I/O expander

Due to it's more dedicated design, this system is one of the few PlayStation based arcade boards which is neither JAMMA nor JVS compliant. Additionally, due to it's usage in mostly Japanese only video games, it is also a more rare system to come by and expensive when it does.
