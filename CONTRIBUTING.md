# Contributions
Contributions are welcome! Currently we are only accepting pull requests from our [GitHub repository](https://github.com/NaokiS28/PSX-Wiki/tree/main), but we are hoping to allow direct editing in future.
When submitting a PR, please use the following guidelines where possible:
* Verify claims against hardware tests, SDK documentation, or trusted sources - Emulators are *not* a reliable source of information.
* Cite sources where possible (unverified information should be clearly marked) - Please do not cite 'public knowledge' or 'for obvious reasons' if it isn't clear why.
* Follow the existing page structure and formatting conventions - Markdown is preffered where possible.
* Open an issue before making large structural changes - It's more than likely that other editors will want to make sure the changes fall in line with our styles and guidelines.
* Do not submit or post copyrighted material without explicit permission from the original rights holder. This includes but is not limited to official Sony documentation, licensed SDK materials, and proprietary tools. When in doubt, do not post it - You may use register names and other non-copyright infringing items.
